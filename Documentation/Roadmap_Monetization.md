# Roadmap de Producto & Monetización - Teacher Daily Assistant

## 1. Roadmap de Producto a 12 Meses

```
[Q1: Lanzamiento MVP] ───> [Q2: Cloud Sync & Pro] ───> [Q3: SaaS Colegios (B2B)] ───> [Q4: IA Avanzada & API]
 - App Store / TestFlight    - Sincronización Firebase    - Consola Web Directores       - WhatsApp Business API
 - Guardado local SwiftData  - Suscripción Pro Individual - Reportes de Desempeño        - Generación automática
 - Conversión Voz + IA       - Plantillas personalizadas  - Gestión de Matrícula         - Resumen Diario Multiclass
```

### Trimestre 1 (Meses 1-3): Estabilidad del MVP y Lanzamiento
* **Objetivo:** Lograr tracción y validación orgánica con profesores individuales.
* **Hitos:**
  * Publicación de la primera versión Beta en Apple TestFlight.
  * Corrección de errores de reconocimiento de voz en dialectos de Latinoamérica.
  * Publicación en la App Store (Gratuita con Key de OpenAI opcional).
  * Recopilación de feedback de profesores de inicial y primaria.

### Trimestre 2 (Meses 4-6): Cloud Sincronización y Suscripción Pro
* **Objetivo:** Introducir la monetización de usuarios individuales (B2C).
* **Hitos:**
  * Integración con Firebase Cloud Firestore para sincronización multi-dispositivo (iPad + iPhone).
  * Lanzamiento de la versión **Pro** (Suscripción mensual/anual vía StoreKit/In-App Purchases).
  * Almacenamiento ilimitado e historial de actividades superior a 30 días.
  * Redacción IA con claves corporativas del servidor (el usuario ya no necesita su propia API Key).

## 2. Estrategia de Monetización Futura

Para asegurar el crecimiento del producto, implementaremos un modelo híbrido **Freemium** y **SaaS B2B**.
